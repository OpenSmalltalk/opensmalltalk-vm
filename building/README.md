# Building directory hierarchy

This directoy tree contains builds for various OS/processor combinations. Feel free to add new ones for new OS/processor combinations. Please *do not* piggy back off new OS/processor combinations on existing directories.

A meaningfully distinct OS/processor combination is a range of versions of a particular operating system and a range of processors for which a particular build will provide a funcitonal VM. For example, macos64ARMv8 produces VMs that run on all currently supported macos versions on AppleSilicon machines, macos64x64 produces VMs that run on all currently supported macos versions on all 64-bit Intel macs.
